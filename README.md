# Calculator

A desktop calculator built with [gpui-shell](https://gpui-kit.com/shell/) and [Omarchy UI](https://github.com/huacnlee/omarchy-ui).

<img width="472" height="632" alt="image" src="https://github.com/user-attachments/assets/965be7ae-aaec-4ced-8ed1-db9c7620761c" />

## Install gpui-shell

```bash
curl -fsSL https://gpui-kit.com/shell/install.sh | sh
```

## Run

```bash
git clone https://github.com/huacnlee/calculator.git
cd calculator
./run.sh
```

## Keyboard

| Key | Action |
| --- | --- |
| `0`–`9` `.` | Enter a number |
| `+` `-` `*` `/` | Add, subtract, multiply, divide |
| `%` | Percent |
| `Return` / `=` | Equals |
| `Backspace` | Delete the last digit |
| `Escape` / `c` | Clear |
